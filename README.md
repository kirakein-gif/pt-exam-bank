# PT국시

물리치료사 국가시험을 준비하기 위한 **PC 로컬 개인 문제은행**입니다.

## 현재 기능

- 한 문제씩 랜덤 출제
- 답 선택 즉시 채점
- 정답과 해설 표시
- 오답 자동 저장 및 오답만 다시 풀기
- 즐겨찾기
- 오늘 푼 문제 / 정답률 / 연속 정답
- 키보드 단축키: 1~5 답 선택, N 다음 문제, F 즐겨찾기
- 로컬 JSON 문제은행 불러오기

## 실행

1. 저장소를 ZIP으로 다운로드합니다.
2. 압축을 풉니다.
3. `index.html`을 더블클릭합니다.
4. 왼쪽 **문제은행 불러오기**를 누릅니다.
5. 개인용 `questions.local.json` 파일을 선택합니다.

별도 설치나 서버가 필요 없습니다.

## 개인정보 / 저작권 자료

실제 기출 PDF와 문제 데이터는 저장소에 넣지 않습니다.

- 원본 PDF: 조카 PC의 별도 폴더
- 변환된 문제은행: `questions.local.json`
- 학습기록: 사용 중인 PC 브라우저 저장공간

`.gitignore`에서 PDF와 개인 문제은행 파일을 GitHub에 올라가지 않도록 제외합니다.

## 문제은행 JSON 형식

```json
{
  "name": "개인 문제은행",
  "questions": [
    {
      "id": "01-1-001",
      "set": "1회",
      "session": "1교시",
      "subject": "물리치료 기초",
      "number": 1,
      "question": "문제 내용",
      "prompt": "필요한 제시문",
      "choices": ["보기1","보기2","보기3","보기4","보기5"],
      "answer": 3,
      "explanation": "해설 내용",
      "source": "출처 표시"
    }
  ]
}
```
