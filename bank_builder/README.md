# PT국시 문제은행 갱신기

**제작자: 나대현**

문제풀이 프로그램과 별도로 사용하는 **PC 로컬 문제은행 제작 도구**입니다.

## 목적

`문제 PDF + 정답 PDF + 풀이 PDF`를 한 세트로 선택하면, 문제풀이 프로그램에서 불러올 수 있는 개별 JSON 문제은행을 만듭니다.

- PDF는 외부 서버로 전송하지 않습니다.
- OCR도 PC 안에서 수행합니다.
- 현재 사용자가 제공한 **KPTLE 최다빈출 적중문제** 계열 레이아웃에 맞춰 구현했습니다.
- 정답과 풀이가 한 PDF에 같이 있으면 같은 파일을 두 칸에 지정할 수 있습니다.

## 처음 한 번 설치

1. 이 폴더에서 `install.bat`을 실행합니다.
2. Python 패키지와 Tesseract OCR을 설치합니다.
3. 한글 OCR 데이터(`kor`)도 자동으로 준비합니다.

## 실행

`run_bank_builder.bat`을 실행합니다.

화면에서 다음을 지정합니다.

1. 문제 PDF
2. 정답 PDF
3. 풀이 PDF
4. 문제은행 이름
5. 각 PDF에서 사용할 페이지 범위
6. 시작 문제번호 / 끝 문제번호
7. 저장 폴더

그 다음 **문제은행 만들기**를 누릅니다.

## 출력 파일

예를 들어 문제은행 이름이 `1회 1교시 물리치료 기초`이면 다음 두 파일이 만들어집니다.

- `1회 1교시 물리치료 기초.json`
- `1회 1교시 물리치료 기초_검수.html`

JSON은 기존 PT국시 문제풀이 프로그램의 **문제은행 불러오기**에서 바로 선택합니다.

검수 HTML은 OCR 결과를 확인하고 수정하기 위한 화면입니다. 문제, 보기, 정답, 풀이를 수정한 뒤 **수정된 문제은행 JSON 다운로드**를 누르면 보정된 JSON을 받을 수 있습니다.

## 현재 샘플로 테스트하는 값

사용자가 올려 준 샘플에서 1회 1교시 1~10번을 테스트하려면:

- 문제 PDF: `국시 1,2교시.pdf`
- 문제 페이지: `9-10`
- 정답 PDF: `국시 1,2교시 답안지.pdf`
- 정답 페이지: `5`
- 풀이 PDF: `국시 1,2교시 답안지.pdf`
- 풀이 페이지: `5-6`
- 문제번호: `1 ~ 10`

테스트 결과 정답은 다음처럼 인식되어야 합니다.

`3, 3, 2, 1, 3, 3, 3, 2, 5, 4`

## 왜 검수 화면이 필요한가

제공된 PDF는 화면으로는 선명하지만 내부 문자 매핑이 깨져 있어서 일반 PDF 텍스트 추출만으로는 한글이 정상적으로 나오지 않습니다. 이 도구는 페이지를 이미지로 렌더링한 뒤 로컬 OCR로 읽습니다.

따라서 `허파꽈리 → 허파까리`처럼 일부 글자가 틀릴 수 있습니다. 문제은행을 처음 만들 때 검수 HTML에서 한 번 확인하는 방식으로 설계했습니다.

## 개별 문제은행 운영

조카가 원하는 대로 문제은행을 한 파일에 모두 합칠 필요는 없습니다.

예:

- `1회_1교시_물리치료기초.json`
- `1회_1교시_진단평가.json`
- `1회_2교시_물리치료중재.json`
- `1회_2교시_의료관계법규.json`

문제풀이 프로그램에서 그날 공부할 JSON만 불러오면 됩니다.
